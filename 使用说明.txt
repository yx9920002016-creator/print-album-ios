# 排版印相 · PrintAlbum 使用说明书
# 版本: 2026-06-11

═══════════════════════════════════════════
  快速开始
═══════════════════════════════════════════

【电脑运行（浏览器调试）】
  双击 → 启动制作工具.bat
  → 等待编译
  → 浏览器自动弹出

【手机测试（局域网）】
  1. 手机和电脑连同一个 WiFi
  2. 双击 → 启动制作工具.bat
  3. 记下"手机访问"地址（如 http://192.168.1.5:8080）
  4. 手机浏览器打开该地址

【导出 iOS 版本】
  使用 Codemagic 云端编译或 Xcode 本地编译

═══════════════════════════════════════════
  三个页面
═══════════════════════════════════════════

【选片页】按年份筛选 → 评分排序 → 点击选择照片
【排版页】拖拽/缩放/旋转照片和文字 → 切换主题
【预览页】查看完整效果 → 导出 PDF 打印
