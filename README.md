# 排版印相 (PrintAlbum) - Flutter 跨平台 App

📸 手机照片排版打印工具 — 自由排版照片制作实体相册，不限题材。

## 功能

- 📸 **相册选片**：按年份浏览，智能评分筛选，批量选择
- 🎨 **自由排版**：拖拽调整位置、双指缩放、双指旋转
- ✏️ **文字工具**：添加自定义文字，支持拖拽、缩放、旋转
- 🖼 **8套可爱主题**：樱花粉、薄荷绿、奶油黄、薰衣草紫、天空蓝、蜜桃橘、抹茶绿、云朵白
- 🌓 **暗色模式**：自动跟随系统深色/浅色模式
- 📄 **导出 PDF**：一键生成高清 PDF，可直接打印实体相册
- 🌐 **多平台**：支持 Web / iOS，浏览器和手机均可使用

## 快速开始

### 电脑运行（浏览器调试）

双击 `启动制作工具.bat` → 等待编译 → 浏览器自动打开

### 手机运行（局域网测试）

1. 手机和电脑连同一个 WiFi
2. 双击 `启动制作工具.bat`，记下终端显示的"手机访问"地址
3. 手机浏览器打开该地址 → 触屏手势全部支持

### 首次配置

双击 `添加web支持.bat`（仅需一次）→ 双击 `一键环境安装.bat`

### 备份到 GitHub

双击 `上传GitHub备份.bat` → 输入修改说明 → 自动提交并推送
